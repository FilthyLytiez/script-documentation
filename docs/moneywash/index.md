# Money Wash Management

![Money Wash Management](/images/moneywash.jpg)

A player owned laundrette. Dirty money goes in and clean money comes out, minus the owner's cut.

::: info Version 5.0.1
Requires `community_bridge`, `ox_lib` and `oxmysql`. Ships one custom item, the wash token.
:::

## Features

* **Player owned laundrettes.** Buy a business and earn a percentage of everything washed through it.
* **Value based timer.** A wash takes longer the more money is in it.
* **Wash tokens.** Players craft tokens to run the machines.
* **Police interest.** Set a minimum number of police online, and a chance that police are alerted.
* **Machine repair.** Machines can break and cost money to repair.
* **Admin tools.** Place everything in game with `/washcreator`.
