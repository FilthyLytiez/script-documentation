# Recycle System

![Recycle System](/images/recycling.jpg)

A recycling plant. Players search wrecked cars for scrap parts, then feed them into the plant and get raw
materials back.

::: info Version 5.0.1 · Free
Requires `community_bridge`, `ox_lib` and `oxmysql`, plus the animated Recycler prop by Mrs. BzZz.
Get it free from the [Filthy Lytiez store](https://filthylytiez.tebex.io/package/7021623).
:::

## Features

* **Search wrecks.** Search the wrecked cars, buses and trucks around the map for scrap parts. The same wreck cannot
  be searched again straight away.
* **Recycling plant.** Turn scrap parts into steel, aluminum, copper, iron, rubber, glass, scrap metal and
  plastic, and get paid for the work.
* **Animated machine.** The plant runs with an animated smoke effect.
* **Admin tools.** Create, edit and delete recycling centers in game with `/recycle`.
