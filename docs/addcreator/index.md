# Ad Creator

![Ad Creator](/images/addcreator.jpg)

Place adverts around the map that players can walk up to and read. Everything is built in game with a menu, so
nothing is typed by hand.

::: info Version 5.0.0 · Free
Requires `community_bridge`, `ox_lib` and `oxmysql`. No inventory items are needed.
Get it free from the [Filthy Lytiez store](https://filthylytiez.tebex.io/package/7205368).
:::

## Features

* **Adverts anywhere.** Place an advert at any spot on the map. Players walk up to it and read it.
* **Built in game.** Fill in the advert in a menu, aim where it should sit and place it.
* **Job editing.** Choose a job that is allowed to edit an advert later.
* **Notifications.** Adverts show as a notification, with a configurable position and duration.
* **Discord log.** Optionally log every published advert to a Discord webhook.
* **Saved as you go.** Nothing needs restarting after placing an advert.
