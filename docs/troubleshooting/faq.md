# FAQ

## Which frameworks do the scripts support?

Qbox, QBCore and ESX, through `community_bridge`. The same script runs on all of them without changes.

## Which inventories are supported?

ox_inventory, qb-inventory, ps-inventory, qs-inventory, origen, codem and tgiann.

## Do I need to import an SQL file?

No. Each script creates its own tables on first start.

## Can I change prices, payouts and other values?

Yes. Everything you can change lives in the config files listed on each script's configuration page.

## Do the scripts send data anywhere?

No. The update check reads the latest version number and nothing is uploaded.

## How do I report a problem?

See [Support](/troubleshooting/support). Include your version number and the first error from the server
console.
