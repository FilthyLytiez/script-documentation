# Support

Support is handled through our Discord. Open a ticket and we will help you out.

[Join the Filthy Lytiez Discord](https://discord.gg/7CHvRKs4KK)

## Before you ask

1. Set `Config.Debug = true` in the script's config. The console usually says what is wrong.
2. Check [Common issues](/troubleshooting/common-issues) and the [FAQ](/troubleshooting/faq).
3. Note the script version from its `fxmanifest.lua`.

## What to include

* The script name and version
* Your framework, inventory and target
* The first error from the server console
* What you expected to happen and what happened instead
